# Jiawei Jia Academic Homepage · Sidebar Edition

这是贾唯的第二套个人学术主页源码。它采用传统学术主页的左侧个人信息栏与右侧内容布局，并与已有的 `jiaweidoris.github.io` 主页并行保留。

## 自由编辑

- 中英文 Biography、动态、论文、经历、教育与荣誉：编辑 `site-data.js`
- 页面结构：编辑 `index.html`
- 配色、间距与响应式布局：编辑 `styles.css`
- 证件照：替换 `assets/profile.jpeg`

右上角语言按钮会在中文和英文版本间切换并记住访客选择。近期动态只展示已经发表、录用或公开发布的成果；在投论文统一放在 “在投工作 / Under Review” 分组。

公开地址：`https://jiaweidoris.github.io/academic-homepage/`
